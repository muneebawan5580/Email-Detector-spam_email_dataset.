# Spam Email Detection using Machine Learning

This project is a Machine Learning-based Spam Email Detection system that classifies emails as **Spam** or **Ham (Not Spam)**.

## Project Overview

The project includes:

* Data Cleaning
* Exploratory Data Analysis (EDA)
* Feature Engineering
* Text Feature Extraction using TF-IDF
* Train/Test Split
* Classification Models
* Model Evaluation

## Features Used

* Email Subject
* Email Body
* Attachment Status
* Number of Links
* TF-IDF text features

## Machine Learning Models

The following classification models were tested:

* Logistic Regression
* Multinomial Naive Bayes
* Linear SVM
* Random Forest
* K-Nearest Neighbors (KNN)
* Decision Tree
* SGD Classifier

## Evaluation Metrics

Models are evaluated using:

* Accuracy
* Precision
* Recall
* F1-Score
* Confusion Matrix

## Dataset

The dataset contains email information with labels indicating whether an email is **Spam** or **Ham**.

## Tools & Libraries

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* SciPy
* Jupyter Notebook

## Project Goal

The main goal of this project is to build and compare different Machine Learning classification models for detecting spam emails and identify the best-performing model.
